                                                                                      Integer number theory

                                                                                      All functions take and return Expression objects holding integer leaves, so arbitrary precision flows through the existing machinery; passing a non-integer expression raises. (Exception: continued_fraction_rational also accepts rational leaves; the three symbol functions return plain machine integers.)

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.factor_integer in Python, UniffiSession.factorInteger in Kotlin, UniffiSession.factorInteger in Swift, api::Session::factor_integer in Rust.

                                                                                      Diophantine equations#

                                                                                      The two supported Diophantine subclasses are linear equations via the extended Euclidean algorithm and Pell's equation via the continued fraction of D\sqrt{D}D​. General Diophantine solving is undecidable (Matiyasevich–Robinson–Davis–Putnam) and is out of scope; the solvers return exact integers and never guess.

                                                                                      solve_linear_diophantine#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.solve_linear_diophantine in Python, UniffiSession.solveLinearDiophantine in Kotlin, UniffiSession.solveLinearDiophantine in Swift, api::number_theory::Session::solve_linear_diophantine in Rust.

                                                                                      General integer solution of a1x1+…+anxn=ca_1 x_1 + \ldots + a_n x_n = ca1​x1​+…+an​xn​=c, returned as the parametric coordinates — one expression per unknown, affine in fresh integer parameter symbols (diophantine_parameter_k) shared across the coordinates so that choosing any integers for the parameters yields a solution tuple. The list is empty when the equation has no integer solution (gcd⁡(ai)∤c\gcd(a_i) \nmid cgcd(ai​)∤c). All coefficients and the constant must be integer expression leaves.

                                                                                      solve_linear_diophantine_system#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.solve_linear_diophantine_system in Python, UniffiSession.solveLinearDiophantineSystem in Kotlin, UniffiSession.solveLinearDiophantineSystem in Swift, api::number_theory::Session::solve_linear_diophantine_system in Rust.

                                                                                      General integer solution of the rectangular system Ax=bA x = bAx=b, returned as one parametric coordinate expression per column of A. The coordinates share fresh integer parameter symbols and describe the complete affine integer lattice of solutions. The list is empty when the system has no integer solution, an entry is not an integer expression leaf, or the dimensions do not agree.

                                                                                      solve_pell#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.solve_pell in Python, UniffiSession.solvePell in Kotlin, UniffiSession.solvePell in Swift, api::number_theory::Session::solve_pell in Rust.

                                                                                      Fundamental solution [x, y] of x2−Dy2=1x^2 - D y^2 = 1x2−Dy2=1 for a positive non-square integer D, the smallest positive solution from which all others are generated by the recurrence xk+1=x1xk+Dy1ykx_{k+1} = x_1 x_k + D y_1 y_kxk+1​=x1​xk​+Dy1​yk​, yk+1=x1yk+y1xky_{k+1} = x_1 y_k + y_1 x_kyk+1​=x1​yk​+y1​xk​. The list is empty when D is a perfect square or non-positive (no nontrivial fundamental solution).

                                                                                      solve_negative_pell#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.solve_negative_pell in Python, UniffiSession.solveNegativePell in Kotlin, UniffiSession.solveNegativePell in Swift, api::number_theory::Session::solve_negative_pell in Rust.

                                                                                      Fundamental solution [x, y] of the negative-Pell equation x2−Dy2=−1x^2 - D y^2 = -1x2−Dy2=−1 when it is solvable (exactly when the continued fraction of D\sqrt{D}D​ has odd period), and an empty list otherwise.

                                                                                      pell_solutions#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.pell_solutions in Python, UniffiSession.pellSolutions in Kotlin, UniffiSession.pellSolutions in Swift, api::number_theory::Session::pell_solutions in Rust.

                                                                                      The first count positive solutions of x2−Dy2=1x^2 - D y^2 = 1x2−Dy2=1, materialised from the fundamental solution by the Pell recurrence and returned as a flat list [x1,y1,x2,y2,…][x_1, y_1, x_2, y_2, \ldots][x1​,y1​,x2​,y2​,…]. Empty when D has no fundamental solution.
