                                                                Series and residues

                                                                taylor_series#

                                                                Not exposed by the WASM / JavaScript bindings. Available as AssumptionScope.taylor_series in Python, UniffiAssumptionScope.taylorSeries in Kotlin, UniffiAssumptionScope.taylorSeries in Swift, api::AssumptionScope::taylor_series in Rust.

                                                                Truncated Taylor expansion about expansion_point, keeping terms of degree strictly less than order (the remainder is O((x−a)order⁡)O((x-a)^{\operatorname{order}})O((x−a)order). Returns the truncated polynomial, not a series object; order = 0 returns zero. Coefficients are computed exactly by repeated symbolic differentiation.

                                                                maclaurin_series#

                                                                Not exposed by the WASM / JavaScript bindings. Available as Context.maclaurin_series in Python, UniffiExpression.maclaurinSeries in Kotlin, UniffiExpression.maclaurinSeries in Swift, api::analysis::Session::maclaurin_series in Rust.

                                                                taylor_series specialised to expansion point 0.

                                                                laurent_series#

                                                                Not exposed by the WASM / JavaScript bindings. Available as Context.laurent_series in Python, UniffiExpression.laurentSeries in Kotlin, UniffiExpression.laurentSeries in Swift, api::Expression::laurent_series in Rust.

                                                                Truncated Laurent expansion at center: every (variable⁡−center⁡)k(\operatorname{variable} - \operatorname{center})^k(variable−center)k term with −m≤k<order⁡-m \le k < \operatorname{order}−m≤k<order, where m is the pole order. Analytic points degrade to the Taylor expansion. At an essential singularity (where pole_order declines) the result is an unevaluated series_unevaluated(...) placeholder, because no finite truncation of the principal part is correct.

                                                                Expression method

                                                                residue(variable: string, center: Expression): Expression

                                                                Coefficient of (variable⁡−center⁡)−1(\operatorname{variable} - \operatorname{center})^{-1}(variable−center)−1 in the Laurent expansion at center. Analytic/removable points give 0; simple poles use the limit of (x−c)f(x - c) f(x−c)f; higher poles use the derivative formula. Essential singularities return an unevaluated residue_unevaluated(...) placeholder. Rational functions use exact polynomial valuations and formal series division, so explicit algebraic centers do not need to occur as structural factors.

                                                                pole_order#

                                                                Not exposed by the WASM / JavaScript bindings. Available as Context.pole_order in Python, UniffiExpression.poleOrder in Kotlin, UniffiExpression.poleOrder in Swift, api::analysis::Session::pole_order in Rust.

                                                                Order of the singularity at center: 0 for analytic/removable points, m≥1m \ge 1m≥1 for a pole of order mmm. Returns None (undefined in JS) when no order ≤16\leq 16≤16 can be certified — the essential-singularity / undecidable verdict. Notes: this is the one series entry returning a plain integer, mirroring the core classifier; it never returns an unevaluated form. For a rational function at an exact algebraic center, the order is obtained from the square-free multiplicities of its numerator and denominator.

Call it through the generated symi.raw layer, whose entries are listed with their wasm-bindgen signatures above, and read Migration for the ownership rules that apply there.
