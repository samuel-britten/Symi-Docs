                                                                                      Combinatorics

                                                                                      Same convention as integer number theory: integer-leaf expressions in, integer-leaf expressions out; non-integer input raises, as do arguments outside each function's domain (negative counts, …).

                                                                                      falling_factorial#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.falling_factorial in Python, UniffiSession.fallingFactorial in Kotlin, UniffiSession.fallingFactorial in Swift, api::Session::falling_factorial in Rust.

                                                                                      base⁡(base⁡−1)⋯(base⁡−length⁡+1)\operatorname{base}(\operatorname{base}-1)\cdots(\operatorname{base}-\operatorname{length}+1)base(base−1)⋯(base−length+1); length must be a non-negative integer, base may be any integer.

                                                                                      rising_factorial#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.rising_factorial in Python, UniffiSession.risingFactorial in Kotlin, UniffiSession.risingFactorial in Swift, api::Session::rising_factorial in Rust.

                                                                                      base⁡(base⁡+1)⋯(base⁡+length⁡−1)\operatorname{base}(\operatorname{base}+1)\cdots(\operatorname{base}+\operatorname{length}-1)base(base+1)⋯(base+length−1) (the Pochhammer symbol on integers).

                                                                                      stirling_first_signed#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.stirling_first_signed in Python, UniffiSession.stirlingFirstSigned in Kotlin, UniffiSession.stirlingFirstSigned in Swift, api::Session::stirling_first_signed in Rust.

                                                                                      Signed Stirling number of the first kind s(n, k).

                                                                                      stirling_second#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.stirling_second in Python, UniffiSession.stirlingSecond in Kotlin, UniffiSession.stirlingSecond in Swift, api::Session::stirling_second in Rust.

                                                                                      Stirling number of the second kind S(n, k).

                                                                                      bell_number#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.bell_number in Python, UniffiSession.bellNumber in Kotlin, UniffiSession.bellNumber in Swift, api::Session::bell_number in Rust.

                                                                                      The n-th Bell number.

                                                                                      catalan_number#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.catalan_number in Python, UniffiSession.catalanNumber in Kotlin, UniffiSession.catalanNumber in Swift, api::Session::catalan_number in Rust.

                                                                                      The n-th Catalan number.

                                                                                      fibonacci_number#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.fibonacci_number in Python, UniffiSession.fibonacciNumber in Kotlin, UniffiSession.fibonacciNumber in Swift, api::Session::fibonacci_number in Rust.

                                                                                      The n-th Fibonacci number (F(0) = 0, F(1) = 1).

                                                                                      partition_count#

                                                                                      Not exposed by the WASM / JavaScript bindings. Available as Context.partition_count in Python, UniffiSession.partitionCount in Kotlin, UniffiSession.partitionCount in Swift, api::Session::partition_count in Rust.

                                                                                      Number of integer partitions p(n).

                                                                                      multinomial#

                                                                                      Raw WebAssembly: Default context

                                                                                      multinomial(parts: Expression[]): Expression
                                                                                      Calling forms

                                                                                      Raw WebAssembly: Explicit context: Context.multinomial

                                                                                      multinomial(parts: Expression[]): Expression

                                                                                      Multinomial coefficient (∑parts⁡)!/∏(part⁡i!)(\sum \operatorname{parts})! / \prod (\operatorname{part}_i!)(∑parts)!/∏(parti​!); parts must be non-negative integers.

                                                                                      Example#

                                                                                      This family is not part of the recommended JavaScript facade in this release. Call it through the generated symi.raw layer, whose entries are listed with their wasm-bindgen signatures above, and read Migration for the ownership rules that apply there.
