                                                                Combinatorics

                                                                Same convention as integer number theory: integer-leaf expressions in, integer-leaf expressions out; non-integer input raises, as do arguments outside each function's domain (negative counts, …).

                                                                falling_factorial#

                                                                Not exposed by the WASM / JavaScript bindings. Available as Context.falling_factorial in Python, UniffiSession.fallingFactorial in Kotlin, UniffiSession.fallingFactorial in Swift, api::Session::falling_factorial in Rust.

                                                                base⁡(base⁡−1)⋯(base⁡−length⁡+1)\operatorname{base}(\operatorname{base}-1)\cdots(\operatorname{base}-\operatorname{length}+1)base(base−1)⋯(base−length+1); length must be a non-negative integer, base may be any integer.

                                                                rising_factorial#

                                                                Not exposed by the WASM / JavaScript bindings. Available as Context.rising_factorial in Python, UniffiSession.risingFactorial in Kotlin, UniffiSession.risingFactorial in Swift, api::Session::rising_factorial in Rust.

                                                                base⁡(base⁡+1)⋯(base⁡+length⁡−1)\operatorname{base}(\operatorname{base}+1)\cdots(\operatorname{base}+\operatorname{length}-1)base(base+1)⋯(base+length−1) (the Pochhammer symbol on integers).

                                                                Signed Stirling number of the first kind s(n, k).
