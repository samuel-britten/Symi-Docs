1//! The control record an embedder writes to stop a call it cannot otherwise reach.
2//!
3//! [`Session::cancel_operation`](crate::api::Session::cancel_operation) is how a caller inside the
4//! process stops one running call. An embedder that entered the library through a synchronous
5//! boundary cannot use it, because the thread that would make that call is the one blocked inside
6//! the mathematics. What such an embedder does have is the memory the library runs in.
7//!
8//! This module publishes a fixed array of words in that memory. A host reserves one word before
9//! it starts a unit of work, keeps the index and ticket it is given, and — from wherever it is
10//! standing — stores the ticket into the word to ask the work to stop. Every call started on the
11//! reserving thread while the reservation is installed observes the word, including the tasks
12//! those calls fork onto other threads, so one store stops a whole nest of calls. Releasing the
13//! reservation clears the word.
14//!
15//! Tickets are what make the array safe to reuse: a store that arrives after the work it named
16//! has returned carries a ticket the next reservation of that word does not answer to, so a late
17//! request can only fail to stop something. It can never stop a call that started afterwards.
18
19pub use crate::operation::{
20    HOST_CANCELLATION_SLOT_COUNT, HostCancellationSlot, host_cancellation_control_address,
21    host_cancellation_control_byte_length, host_cancellation_requested,
22    host_cancellation_slot_count, host_cancellation_slot_ticket, release_host_cancellation_slot,
23    request_host_cancellation, reserve_host_cancellation_slot,
24};
