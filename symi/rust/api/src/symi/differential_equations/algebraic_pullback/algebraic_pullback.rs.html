1// Algebraic pullbacks of second-order special-function equations.
2//
3// A great many named second-order equations are not distinct equations at all: they are one
4// normal form read in a different coordinate and against a different gauge. Writing
5//
6//   y(x) = g(x) * v(h(x))
7//
8// carries a solution `v` of the normal form in `z` back to a solution `y` of the source equation
9// in `x`. Recognising a source equation as such a pullback is therefore the difference between
10// answering it in closed form and declining it, and it is a *general* recognition: nothing here
11// reads the literal coefficients of any particular equation.
12//
13// The chain rule applied to the substitution above turns the normalized source operator
14// `y'' + P y' + Q y` into
15//
16//   g (h')^2 v_zz + (2 g' h' + g h'' + P g h') v_z + (g'' + P g' + Q g) v,
17//
18// so dividing by the recorded multiplier `g (h')^2` — which must be nonzero on the chart, and is
19// carried as a domain obligation rather than assumed — gives the transformed coefficients
20//
21//   B(x) = (2 g'/g + h''/h' + P) / h',        C(x) = (g''/g + P g'/g + Q) / (h')^2.
22//
23// The source is a pullback of a target normal form `v_zz + b(z) v_z + c(z) v = 0` exactly when
24// `B(x) = b(h(x))` and `C(x) = c(h(x))` hold identically. Both are exact identities in `x`, and
25// both are decided here by zero-equivalence rather than by structural comparison, which is what
26// makes a perturbed equation fail instead of being quietly rounded to the nearest named one.
27//
28// The two identities are used in opposite directions, and that is the whole algorithm. The first
29// one *determines* the gauge: writing `L = g'/g`, it says
30//
31//   L = (1/2) * (b(h) h' - h''/h' - P),
32//
33// which is a formula, not a search. Substituting it into the second identity eliminates `g`
34// entirely, because `g''/g = L' + L^2`, leaving
35//
36//   L' + L^2 + P L + Q = c(h) (h')^2                                              (*)
37//
38// as a single equation in the pullback alone. Discovery is then the job of finding an `h` that
39// satisfies (*), and the gauge follows afterwards by one quadrature of the formula above — whose
40// result is itself replayed against `L` rather than trusted.
41//
42// This module closes the cylinder normal forms
43//
44//   v_zz + v_z/z + (1 - nu^2/z^2) v = 0      and     v_zz + v_z/z - (1 + nu^2/z^2) v = 0
45//
46// over the algebraic pullbacks `h(x) = alpha * (x - center)^p` with rational `p`. That family is
47// bounded but it is not enumerated: for a cylinder target `b(z) = 1/z`, so `b(h) h' = h'/h`, and
48// for a power pullback `h'/h - h''/h' = 1/w` identically in both `alpha` and `p`. The gauge
49// logarithmic derivative is therefore known before the pullback is, which turns (*) into a
50// statement about a *computable* function of the source alone:
51//
52//   R(x) := L' + L^2 + P L + Q  must equal  K w^(2p-2) - M w^(-2),
53//
54// with `K = ±alpha^2 p^2` and `M = nu^2 p^2`. Reading the exponents of `R` yields `p`; reading its
55// coefficients yields the scaling and the order. The sign of `K` chooses between the oscillatory
56// and the modified family, so neither has to be guessed either. An equation whose `R` carries any
57// other exponent is not a power pullback of a cylinder equation and is declined by name.
58//
59// Independence of the returned pair is established, not assumed. The Wronskian of a pullback pair
60// is `W_x = g^2 h' * W_z(h)`, and the cylinder pairs have the exact Wronskians `2/(pi z)` and
61// `-1/z`; composing them gives a closed form that is nonvanishing wherever the chart obligations
62// hold, for every order including the integer orders at which the two Bessel functions of the
63// first kind cease to be independent of one another.

86/// Public native enumeration named `cylinder_family`.
87///
88/// Which of the two cylinder normal forms a pullback lands in. They differ only in the sign the
89/// leading potential carries, and that sign is a decided fact about the source rather than a
90/// choice, so the two are one recognition rather than two.
91#[derive(Debug, Clone, Copy, PartialEq, Eq)]
92pub enum CylinderFamily {
93    /// The oscillatory form `v_zz + v_z/z + (1 - nu^2/z^2) v = 0`, solved by `bessel_j`/`bessel_y`.
94    Oscillatory,
95    /// The modified form `v_zz + v_z/z - (1 + nu^2/z^2) v = 0`, solved by `bessel_i`/`bessel_k`.
96    Modified,
97}
98
99impl CylinderFamily {
100    /// Returns the two builtin functions whose pair is the normal form's fundamental system.
101    fn fundamental_builtins(self) -> (BuiltinFunction, BuiltinFunction) {
102        match self {
103            CylinderFamily::Oscillatory => (BuiltinFunction::BesselJ, BuiltinFunction::BesselY),
104            CylinderFamily::Modified => (BuiltinFunction::BesselI, BuiltinFunction::BesselK),
105        }
106    }
107
108    /// Returns the prefix the family's free constants are minted under.
109    fn constant_prefix(self) -> &'static str {
110        match self {
111            CylinderFamily::Oscillatory => "constant_bessel_pullback",
112            CylinderFamily::Modified => "constant_modified_bessel_pullback",
113        }
114    }
115
116    /// Returns the exact Wronskian of the normal form's fundamental pair at the coordinate.
117    ///
118    /// `W_z(bessel_j(nu, z), bessel_y(nu, z)) = 2/(pi z)` and
119    /// `W_z(bessel_i(nu, z), bessel_k(nu, z)) = -1/z`. Both are independent of the order, which is
120    /// exactly why they decide independence at the integer orders where an order-reflected pair
121    /// would not be a basis.
122    fn normal_form_wronskian(
123        self,
124        context: &Context,
125        coordinate: &ExpressionReference,
126    ) -> ExpressionReference {
127        let reciprocal = builders::power(
128            context,
129            Arc::clone(coordinate),
130            builders::integer(context, Integer::from(-1)),
131        );
132        match self {
133            CylinderFamily::Oscillatory => {
134                let two = builders::integer(context, Integer::from(2));
135                let inverse_pi = builders::power(
136                    context,
137                    builders::constant(context, BuiltinConstant::Pi),
138                    builders::integer(context, Integer::from(-1)),
139                );
140                builders::product(context, vec![two, inverse_pi, reciprocal])
141            }
142            CylinderFamily::Modified => builders::negate(context, reciprocal),
143        }
144    }
145}

147/// Public native data structure named `algebraic_pullback_certificate`.
148///
149/// The recognised substitution together with everything needed to check it independently: the
150/// gauge and pullback themselves, the order the target normal form is read at, and the exact
151/// Wronskian of the resulting pair.
152#[derive(Debug, Clone)]
153pub struct AlgebraicPullbackCertificate {
154    /// Stores the gauge factor `g(x)` the substitution `y = g * v(h)` carries.
155    pub gauge: ExpressionReference,
156    /// Stores the pullback coordinate `h(x)`.
157    pub pullback: ExpressionReference,
158    /// Stores the order the target normal form is read at.
159    pub order: ExpressionReference,
160    /// Stores which cylinder normal form the source pulls back from.
161    pub family: CylinderFamily,
162    /// Stores the exact Wronskian of the returned pair, in the source coordinate.
163    pub wronskian: ExpressionReference,
164    /// Stores the chart the substitution is stated on.
165    pub domain_obligations: Vec<OrdinaryDifferentialEquationDomainObligation>,
166}

168/// The rational exponents a power pullback may carry.
169///
170/// The bound is on the *reported* exponent rather than on a search: `p` is read off the source
171/// below, and this only refuses to name a substitution whose exponent is so large that the
172/// transformed coefficients would be beyond independent replay. A refusal here is a decline.
173const MAXIMUM_PULLBACK_EXPONENT_MAGNITUDE: i64 = 16;

175/// Recognises a source equation as an algebraic pullback of a cylinder normal form.
176///
177/// Returns the certified substitution, or `None` when the source is not a power pullback of either
178/// cylinder family — which includes every case where the transformed-coefficient identity cannot
179/// be *proved*, not merely those where it is structurally unfamiliar.
180///
181/// Two restrictions are applied before any pullback is looked for. Normalizing divides by the
182/// leading coefficient, so a coefficient that vanishes identically is refused outright — it is not
183/// a second-order operator — while one that merely may vanish somewhere leaves the certificate
184/// stated away from those points, which is what its obligation records. And a constant-coefficient
185/// operator, which really is a pullback of the half-order cylinder equation against a square-root
186/// gauge, is declined: answering it that way would be true and useless, since its solutions are
187/// exponentials and the cylinder form would drag a positive-real chart onto an equation that is
188/// regular on the whole line.
189pub fn discover_cylinder_pullback(
190    context: &Context,
191    equation: &ExpressionReference,
192    function: FunctionIdentifier,
193    independent_variable: SymbolIdentifier,
194) -> Option<AlgebraicPullbackCertificate> {
195    let (leading, first, value) = extract_second_order_linear_coefficients(
196        context,
197        equation,
198        function,
199        independent_variable,
200    )?;
201    if is_nonzero(&leading, &context.symbol_table) == TruthValue::No {
202        return None;
203    }
204    let normalized_first = builders::divide(context, first, Arc::clone(&leading));
205    let normalized_value = builders::divide(context, value, Arc::clone(&leading));
206    if !depends_on(&normalized_first, independent_variable)
207        && !depends_on(&normalized_value, independent_variable)
208    {
209        return None;
210    }
211    for center in pullback_centers(context, equation, independent_variable) {
212        if let Some(certificate) = cylinder_pullback_about(
213            context,
214            independent_variable,
215            &normalized_first,
216            &normalized_value,
217            &leading,
218            &center,
219        ) {
220            return Some(certificate);
221        }
222    }
223    None
224}

226/// Builds the fundamental pair of an established pullback.
227///
228/// The pair is `g * (C0 f0(nu, h) + C1 f1(nu, h))` for the target family's two solutions. Both
229/// free constants are returned so a caller can state exactly which data the family carries; a
230/// second-order family that cannot name two independent constants is not a general family.
231pub fn pullback_fundamental_pair(
232    context: &Context,
233    certificate: &AlgebraicPullbackCertificate,
234) -> (ExpressionReference, Vec<SymbolIdentifier>) {
235    let (first_builtin, second_builtin) = certificate.family.fundamental_builtins();
236    let first_solution = builders::function_call(
237        context,
238        FunctionIdentifier::Builtin(first_builtin),
239        vec![
240            Arc::clone(&certificate.order),
241            Arc::clone(&certificate.pullback),
242        ],
243    );
244    let second_solution = builders::function_call(
245        context,
246        FunctionIdentifier::Builtin(second_builtin),
247        vec![
248            Arc::clone(&certificate.order),
249            Arc::clone(&certificate.pullback),
250        ],
251    );
252    let prefix = certificate.family.constant_prefix();
253    let first_constant = context.symbol_table.fresh(&format!("{prefix}_0"));
254    let second_constant = context.symbol_table.fresh(&format!("{prefix}_1"));
255    let first_term = builders::product(
256        context,
257        vec![
258            context
259                .interner
260                .intern(ExpressionKind::Symbol(first_constant)),
261            first_solution,
262        ],
263    );
264    let second_term = builders::product(
265        context,
266        vec![
267            context
268                .interner
269                .intern(ExpressionKind::Symbol(second_constant)),
270            second_solution,
271        ],
272    );
273    let combination = builders::sum(context, vec![first_term, second_term]);
274    let family = builders::product(context, vec![Arc::clone(&certificate.gauge), combination]);
275    (family, vec![first_constant, second_constant])
276}

278/// Collects the candidate centres a power pullback may be written about.
279///
280/// The origin is always a candidate. Beyond it, only centres the source equation already names are
281/// considered: a shifted pullback `(x - center)^p` leaves that exact base behind in the
282/// coefficients, so reading the bases the equation contains finds every shift that is written
283/// rather than guessing at shifts that are not.
284fn pullback_centers(
285    context: &Context,
286    equation: &ExpressionReference,
287    independent_variable: SymbolIdentifier,
288) -> Vec<ExpressionReference> {
289    let mut centers = vec![builders::zero(context)];
290    let mut bases = Vec::new();
291    collect_power_bases(equation, &mut bases);
292    for base in bases {
293        let Some(center) = linear_base_center(context, &base, independent_variable) else {
294            continue;
295        };
296        if !centers.iter().any(|existing| existing.kind == center.kind) {
297            centers.push(center);
298        }
299    }
300    centers
301}
302
303fn collect_power_bases(expression: &ExpressionReference, bases: &mut Vec<ExpressionReference>) {
304    match &expression.kind {
305        ExpressionKind::Sum(children) | ExpressionKind::Product(children) => {
306            for child in children {
307                collect_power_bases(child, bases);
308            }
309        }
310        ExpressionKind::Power(base, exponent) => {
311            bases.push(Arc::clone(base));
312            collect_power_bases(base, bases);
313            collect_power_bases(exponent, bases);
314        }
315        ExpressionKind::FunctionCall(_, arguments) => {
316            for argument in arguments {
317                collect_power_bases(argument, bases);
318            }
319        }
320        _ => {}
321    }
322}

324/// Reads `center` from a base of the exact shape `x - center`, where `center` does not involve `x`.
325fn linear_base_center(
326    context: &Context,
327    base: &ExpressionReference,
328    independent_variable: SymbolIdentifier,
329) -> Option<ExpressionReference> {
330    let ExpressionKind::Sum(terms) = &base.kind else {
331        return None;
332    };
333    let variable = context
334        .interner
335        .intern(ExpressionKind::Symbol(independent_variable));
336    let mut constant_terms = Vec::new();
337    let mut saw_variable = false;
338    for term in terms {
339        if term.kind == variable.kind {
340            if saw_variable {
341                return None;
342            }
343            saw_variable = true;
344        } else if depends_on(term, independent_variable) {
345            return None;
346        } else {
347            constant_terms.push(Arc::clone(term));
348        }
349    }
350    if !saw_variable || constant_terms.is_empty() {
351        return None;
352    }
353    Some(builders::negate(
354        context,
355        builders::sum(context, constant_terms),
356    ))
357}

359/// Attempts the pullback recognition about one centre.
360///
361/// For a cylinder target `b(z) = 1/z`, so the gauge is fixed by `h'/h - h''/h' - P`, and for any
362/// power pullback about this centre that first difference is `1/(x - center)` whatever the scaling
363/// and the exponent are. The gauge is therefore known before the pullback is, which is what lets
364/// the potential below be a computable function of the source rather than of a guess.
365fn cylinder_pullback_about(
366    context: &Context,
367    independent_variable: SymbolIdentifier,
368    normalized_first: &ExpressionReference,
369    normalized_value: &ExpressionReference,
370    leading: &ExpressionReference,
371    center: &ExpressionReference,
372) -> Option<AlgebraicPullbackCertificate> {
373    let variable = context
374        .interner
375        .intern(ExpressionKind::Symbol(independent_variable));
376    let shifted = builders::subtract(context, variable, Arc::clone(center));
377    let inverse_shifted = builders::power(
378        context,
379        Arc::clone(&shifted),
380        builders::integer(context, Integer::from(-1)),
381    );
382    let half = builders::rational(context, Integer::from(1), Integer::from(2));
383    let gauge_logarithmic_derivative = builders::product(
384        context,
385        vec![
386            half,
387            builders::subtract(
388                context,
389                inverse_shifted,
390                ExpressionReference::clone(normalized_first),
391            ),
392        ],
393    );
394    let residual_potential = gauge_eliminated_potential(
395        context,
396        independent_variable,
397        &gauge_logarithmic_derivative,
398        normalized_first,
399        normalized_value,
400    );
401    let (exponent, scaling_square, order_square) =
402        read_power_pullback_data(context, &residual_potential, &shifted, independent_variable)?;
403    let (family, scaling) = family_and_scaling(context, &scaling_square)?;
404    let order = exact_square_root(context, &order_square)?;
405    let pullback = builders::product(
406        context,
407        vec![
408            scaling,
409            builders::power(context, Arc::clone(&shifted), exponent.clone()),
410        ],
411    );
412    let surrogate = ChartSurrogate::new(context, independent_variable, center);
413    certify_pullback(
414        context,
415        independent_variable,
416        &surrogate,
417        normalized_first,
418        normalized_value,
419        leading,
420        &gauge_logarithmic_derivative,
421        &pullback,
422        &order,
423        family,
424        &shifted,
425    )
426}

428/// Computes `R = L' + L^2 + P L + Q`, the potential the gauge has been eliminated from.
429fn gauge_eliminated_potential(
430    context: &Context,
431    independent_variable: SymbolIdentifier,
432    gauge_logarithmic_derivative: &ExpressionReference,
433    normalized_first: &ExpressionReference,
434    normalized_value: &ExpressionReference,
435) -> ExpressionReference {
436    let derivative = differentiate(context, gauge_logarithmic_derivative, independent_variable);
437    let square = builders::power(
438        context,
439        ExpressionReference::clone(gauge_logarithmic_derivative),
440        builders::integer(context, Integer::from(2)),
441    );
442    let transported = builders::product(
443        context,
444        vec![
445            ExpressionReference::clone(normalized_first),
446            ExpressionReference::clone(gauge_logarithmic_derivative),
447        ],
448    );
449    let total = builders::sum(
450        context,
451        vec![
452            derivative,
453            square,
454            transported,
455            ExpressionReference::clone(normalized_value),
456        ],
457    );
458    crate::simplify::simplify(context, total)
459}

461/// Reads the pullback exponent, the squared scaling and the squared order out of `R`.
462///
463/// `R` must be exactly `K w^(2p-2) - M w^(-2)`: one leading term whose exponent names `p`, and an
464/// optional inverse-square term whose coefficient names the order. Any further exponent means the
465/// source is not a power pullback of a cylinder equation, and is declined rather than truncated.
466fn read_power_pullback_data(
467    context: &Context,
468    residual_potential: &ExpressionReference,
469    shifted: &ExpressionReference,
470    independent_variable: SymbolIdentifier,
471) -> Option<(
472    ExpressionReference,
473    ExpressionReference,
474    ExpressionReference,
475)> {
476    let terms = laurent_terms(context, residual_potential, shifted, independent_variable)?;
477    let inverse_square = Rational::from_integers(Integer::from(-2), Integer::from(1));
478    let mut leading: Option<(Rational, ExpressionReference)> = None;
479    let mut order_coefficient = builders::zero(context);
480    for (exponent, coefficient) in terms {
481        if exponent == inverse_square {
482            order_coefficient = coefficient;
483        } else if leading.is_some() {
484            return None;
485        } else {
486            leading = Some((exponent, coefficient));
487        }
488    }
489    let (leading_exponent, leading_coefficient) = leading?;
490    let two = Rational::from_integers(Integer::from(2), Integer::from(1));
491    let exponent = (leading_exponent + two.clone()) / two;
492    if exponent == Rational::from_integers(Integer::from(0), Integer::from(1)) {
493        return None;
494    }
495    let (numerator, denominator) = exponent.to_numerator_and_denominator();
496    let magnitude = Integer::from(MAXIMUM_PULLBACK_EXPONENT_MAGNITUDE);
497    if Integer::from(numerator) > magnitude || Integer::from(denominator) > magnitude {
498        return None;
499    }
500    let exponent_expression = rational_expression(context, &exponent);
501    let exponent_square = builders::power(
502        context,
503        exponent_expression.clone(),
504        builders::integer(context, Integer::from(2)),
505    );
506    let scaling_square = builders::divide(
507        context,
508        leading_coefficient,
509        ExpressionReference::clone(&exponent_square),
510    );
511    let order_square = builders::divide(
512        context,
513        builders::negate(context, order_coefficient),
514        exponent_square,
515    );
516    Some((exponent_expression, scaling_square, order_square))
517}

519/// Decomposes an expression into `coefficient * shifted^exponent` terms with rational exponents.
520///
521/// Every summand must be a power of the shifted coordinate times a factor the coordinate does not
522/// reach; a summand that mixes the coordinate in any other way makes the whole reading fail, which
523/// is the decline the caller wants rather than a partial decomposition it could misread.
524fn laurent_terms(
525    context: &Context,
526    expression: &ExpressionReference,
527    shifted: &ExpressionReference,
528    independent_variable: SymbolIdentifier,
529) -> Option<Vec<(Rational, ExpressionReference)>> {
530    let mut collected: BTreeMap<String, (Rational, Vec<ExpressionReference>)> = BTreeMap::new();
531    for term in additive_terms(context, expression) {
532        let factors: Vec<ExpressionReference> = match &term.kind {
533            ExpressionKind::Product(children) => children.iter().map(Arc::clone).collect(),
534            _ => vec![Arc::clone(&term)],
535        };
536        let mut exponent = Rational::from_integers(Integer::from(0), Integer::from(1));
537        let mut coefficient_factors = Vec::new();
538        for factor in factors {
539            if let Some(factor_exponent) = shifted_power_exponent(&factor, shifted) {
540                exponent += factor_exponent;
541            } else if depends_on(&factor, independent_variable) {
542                return None;
543            } else {
544                coefficient_factors.push(factor);
545            }
546        }
547        let key = format!("{exponent}");
548        let entry = collected
549            .entry(key)
550            .or_insert_with(|| (exponent, Vec::new()));
551        entry
552            .1
553            .push(builders::product(context, coefficient_factors));
554    }
555    Some(
556        collected
557            .into_values()
558            .map(|(exponent, coefficients)| (exponent, builders::sum(context, coefficients)))
559            .collect(),
560    )
561}

563/// Returns the rational exponent of a factor that is a power of the shifted coordinate.
564fn shifted_power_exponent(
565    factor: &ExpressionReference,
566    shifted: &ExpressionReference,
567) -> Option<Rational> {
568    if factor.kind == shifted.kind {
569        return Some(Rational::from_integers(Integer::from(1), Integer::from(1)));
570    }
571    let ExpressionKind::Power(base, exponent) = &factor.kind else {
572        return None;
573    };
574    if base.kind != shifted.kind {
575        return None;
576    }
577    rational_value(exponent)
578}

580fn rational_value(expression: &ExpressionReference) -> Option<Rational> {
581    match &expression.kind {
582        ExpressionKind::Integer(value) => {
583            Some(Rational::from_integers(value.clone(), Integer::from(1)))
584        }
585        ExpressionKind::Rational(value) => Some(value.clone()),
586        _ => None,
587    }
588}

590fn rational_expression(context: &Context, value: &Rational) -> ExpressionReference {
591    let (numerator, denominator) = value.to_numerator_and_denominator();
592    let numerator = Integer::from(numerator);
593    let denominator = Integer::from(denominator);
594    let numerator = if *value < Rational::from_integers(Integer::from(0), Integer::from(1)) {
595        -numerator
596    } else {
597        numerator
598    };
599    builders::rational(context, numerator, denominator)
600}

602/// Chooses the cylinder family from the sign of the squared scaling, and extracts the scaling.
603///
604/// The leading potential of the oscillatory form is `+1` and that of the modified form is `-1`, so
605/// the sign the source carries is what decides between them. A squared scaling whose sign cannot
606/// be proved either way names no real chart and declines.
607fn family_and_scaling(
608    context: &Context,
609    scaling_square: &ExpressionReference,
610) -> Option<(CylinderFamily, ExpressionReference)> {
611    let (family, magnitude) =
612        if is_positive(scaling_square, &context.symbol_table) == TruthValue::Yes {
613            (
614                CylinderFamily::Oscillatory,
615                ExpressionReference::clone(scaling_square),
616            )
617        } else if is_negative(scaling_square, &context.symbol_table) == TruthValue::Yes {
618            (
619                CylinderFamily::Modified,
620                builders::negate(context, ExpressionReference::clone(scaling_square)),
621            )
622        } else {
623            return None;
624        };
625    let scaling = exact_square_root(context, &magnitude)?;
626    Some((family, scaling))
627}

629/// Returns a square root of the input whose square replays the input exactly.
630///
631/// The order of a cylinder equation enters only through its square, so either root is equally a
632/// valid order for the same fundamental pair; what is not negotiable is that the root returned
633/// actually squares back, which is checked rather than assumed.
634fn exact_square_root(
635    context: &Context,
636    value: &ExpressionReference,
637) -> Option<ExpressionReference> {
638    let two = builders::integer(context, Integer::from(2));
639    let candidate = match &value.kind {
640        ExpressionKind::Power(base, exponent) if exponent.kind == two.kind => {
641            ExpressionReference::clone(base)
642        }
643        _ => builders::power(
644            context,
645            ExpressionReference::clone(value),
646            builders::rational(context, Integer::from(1), Integer::from(2)),
647        ),
648    };
649    let replayed = builders::power(context, ExpressionReference::clone(&candidate), two);
650    let difference = builders::subtract(context, replayed, ExpressionReference::clone(value));
651    match zero_equivalent(context, &difference, None) {
652        ZeroEquivalenceVerdict::TrueValue => Some(candidate),
653        _ => None,
654    }
655}

657/// Replays the substitution identity and builds the certificate it proves.
658///
659/// Discovery above reads a candidate out of one decomposition of one expression. This function
660/// does not trust any of that: it rebuilds both transformed-coefficient identities from the
661/// concrete gauge and pullback and decides them against zero, so a candidate that the reading
662/// produced but the mathematics does not support is rejected here.
663#[allow(clippy::too_many_arguments)]
664fn certify_pullback(
665    context: &Context,
666    independent_variable: SymbolIdentifier,
667    surrogate: &ChartSurrogate,
668    normalized_first: &ExpressionReference,
669    normalized_value: &ExpressionReference,
670    leading: &ExpressionReference,
671    gauge_logarithmic_derivative: &ExpressionReference,
672    pullback: &ExpressionReference,
673    order: &ExpressionReference,
674    family: CylinderFamily,
675    shifted: &ExpressionReference,
676) -> Option<AlgebraicPullbackCertificate> {
677    let pullback_derivative = differentiate(context, pullback, independent_variable);
678    if is_nonzero(&pullback_derivative, &context.symbol_table) == TruthValue::No {
679        return None;
680    }
681    let transformed_first = transformed_first_coefficient(
682        context,
683        independent_variable,
684        normalized_first,
685        gauge_logarithmic_derivative,
686        &pullback_derivative,
687    );
688    let expected_first = builders::power(
689        context,
690        ExpressionReference::clone(pullback),
691        builders::integer(context, Integer::from(-1)),
692    );
693    if !proves_zero(context, surrogate, &transformed_first, &expected_first) {
694        return None;
695    }
696    let residual_potential = gauge_eliminated_potential(
697        context,
698        independent_variable,
699        gauge_logarithmic_derivative,
700        normalized_first,
701        normalized_value,
702    );
703    let expected_potential = builders::product(
704        context,
705        vec![
706            cylinder_potential(context, family, pullback, order),
707            builders::power(
708                context,
709                ExpressionReference::clone(&pullback_derivative),
710                builders::integer(context, Integer::from(2)),
711            ),
712        ],
713    );
714    if !proves_zero(context, surrogate, &residual_potential, &expected_potential) {
715        return None;
716    }
717    let gauge = integrated_gauge(context, surrogate, gauge_logarithmic_derivative)?;
718    let wronskian = pullback_wronskian(context, family, &gauge, pullback, &pullback_derivative);
719    let domain_obligations =
720        chart_obligations(leading, &gauge, pullback, &pullback_derivative, shifted);
721    Some(AlgebraicPullbackCertificate {
722        gauge,
723        pullback: ExpressionReference::clone(pullback),
724        order: ExpressionReference::clone(order),
725        family,
726        wronskian,
727        domain_obligations,
728    })
729}

731/// Builds `B(x) = (2 g'/g + h''/h' + P) / h'`, the transformed first-derivative coefficient.
732fn transformed_first_coefficient(
733    context: &Context,
734    independent_variable: SymbolIdentifier,
735    normalized_first: &ExpressionReference,
736    gauge_logarithmic_derivative: &ExpressionReference,
737    pullback_derivative: &ExpressionReference,
738) -> ExpressionReference {
739    let second = differentiate(context, pullback_derivative, independent_variable);
740    let curvature = builders::divide(
741        context,
742        second,
743        ExpressionReference::clone(pullback_derivative),
744    );
745    let doubled_gauge = builders::product(
746        context,
747        vec![
748            builders::integer(context, Integer::from(2)),
749            ExpressionReference::clone(gauge_logarithmic_derivative),
750        ],
751    );
752    let total = builders::sum(
753        context,
754        vec![
755            doubled_gauge,
756            curvature,
757            ExpressionReference::clone(normalized_first),
758        ],
759    );
760    builders::divide(
761        context,
762        total,
763        ExpressionReference::clone(pullback_derivative),
764    )
765}

767/// Builds the cylinder normal form's value coefficient `c(z)` at the pullback coordinate.
768fn cylinder_potential(
769    context: &Context,
770    family: CylinderFamily,
771    pullback: &ExpressionReference,
772    order: &ExpressionReference,
773) -> ExpressionReference {
774    let order_square = builders::power(
775        context,
776        ExpressionReference::clone(order),
777        builders::integer(context, Integer::from(2)),
778    );
779    let inverse_square = builders::power(
780        context,
781        ExpressionReference::clone(pullback),
782        builders::integer(context, Integer::from(-2)),
783    );
784    let order_term = builders::negate(
785        context,
786        builders::product(context, vec![order_square, inverse_square]),
787    );
788    let leading = match family {
789        CylinderFamily::Oscillatory => builders::one(context),
790        CylinderFamily::Modified => builders::integer(context, Integer::from(-1)),
791    };
792    builders::sum(context, vec![leading, order_term])
793}

795/// Recovers the gauge by one quadrature and replays its logarithmic derivative.
796///
797/// The quadrature is the only step whose result is not already determined by the reading above, so
798/// it is the one that most needs checking: the returned gauge is accepted only when differentiating
799/// it reproduces the logarithmic derivative the substitution was built from.
800fn integrated_gauge(
801    context: &Context,
802    surrogate: &ChartSurrogate,
803    gauge_logarithmic_derivative: &ExpressionReference,
804) -> Option<ExpressionReference> {
805    let zero = builders::zero(context);
806    if gauge_logarithmic_derivative.kind == zero.kind {
807        return Some(builders::one(context));
808    }
809    let on_chart = surrogate.transport(context, gauge_logarithmic_derivative);
810    let antiderivative = crate::integrate::integrate(context, &on_chart, surrogate.coordinate);
811    if contains_unevaluated_integral(&antiderivative) {
812        return None;
813    }
814    let gauge = exponential_of(context, &antiderivative);
815    let derivative = differentiate(context, &gauge, surrogate.coordinate);
816    let recovered = builders::divide(context, derivative, ExpressionReference::clone(&gauge));
817    let difference =
818        crate::simplify::simplify(context, builders::subtract(context, recovered, on_chart));
819    if zero_equivalent(context, &difference, None) != ZeroEquivalenceVerdict::TrueValue {
820        return None;
821    }
822    Some(surrogate.transport_back(context, &gauge))
823}

825/// Exponentiates an antiderivative, turning its logarithmic part into powers.
826///
827/// A gauge is almost always `exp` of something with logarithms in it, and left in that form it is
828/// both unreadable and opaque to everything downstream. Each `coefficient * log(argument)` summand
829/// is the power `argument^coefficient`, which is the form the answer should carry; whatever is not
830/// logarithmic stays inside a single exponential. The rewrite is exact on the positive chart this
831/// runs on, and the caller replays the result against the logarithmic derivative regardless.
832fn exponential_of(context: &Context, antiderivative: &ExpressionReference) -> ExpressionReference {
833    let mut factors = Vec::new();
834    let mut remaining = Vec::new();
835    for term in additive_terms(context, antiderivative) {
836        match logarithmic_term(context, &term) {
837            Some((argument, coefficient)) => {
838                factors.push(builders::power(context, argument, coefficient))
839            }
840            None => remaining.push(term),
841        }
842    }
843    let residual = builders::sum(context, remaining);
844    let zero = builders::zero(context);
845    if residual.kind != zero.kind {
846        factors.push(builders::function_call(
847            context,
848            FunctionIdentifier::Builtin(BuiltinFunction::Exp),
849            vec![residual],
850        ));
851    }
852    crate::simplify::simplify(context, builders::product(context, factors))
853}
854
855/// Splits a summand of the shape `coefficient * log(argument)` into its argument and coefficient.
856fn logarithmic_term(
857    context: &Context,
858    term: &ExpressionReference,
859) -> Option<(ExpressionReference, ExpressionReference)> {
860    let factors: Vec<ExpressionReference> = match &term.kind {
861        ExpressionKind::Product(children) => children.iter().map(Arc::clone).collect(),
862        _ => vec![Arc::clone(term)],
863    };
864    let mut argument = None;
865    let mut coefficient_factors = Vec::new();
866    for factor in factors {
867        match &factor.kind {
868            ExpressionKind::FunctionCall(
869                FunctionIdentifier::Builtin(BuiltinFunction::Log),
870                arguments,
871            ) if arguments.len() == 1 && argument.is_none() => {
872                argument = Some(ExpressionReference::clone(&arguments[0]));
873            }
874            _ => coefficient_factors.push(factor),
875        }
876    }
877    let argument = argument?;
878    Some((argument, builders::product(context, coefficient_factors)))
879}
880
881fn contains_unevaluated_integral(expression: &ExpressionReference) -> bool {
882    match &expression.kind {
883        ExpressionKind::Integral(_, _, _, _) => true,
884        ExpressionKind::Sum(children) | ExpressionKind::Product(children) => {
885            children.iter().any(contains_unevaluated_integral)
886        }
887        ExpressionKind::Power(base, exponent) => {
888            contains_unevaluated_integral(base) || contains_unevaluated_integral(exponent)
889        }
890        ExpressionKind::FunctionCall(_, arguments) => {
891            arguments.iter().any(contains_unevaluated_integral)
892        }
893        _ => false,
894    }
895}

897/// Builds the Wronskian of the pullback pair, `W_x = g^2 h' W_z(h)`.
898fn pullback_wronskian(
899    context: &Context,
900    family: CylinderFamily,
901    gauge: &ExpressionReference,
902    pullback: &ExpressionReference,
903    pullback_derivative: &ExpressionReference,
904) -> ExpressionReference {
905    let gauge_square = builders::power(
906        context,
907        ExpressionReference::clone(gauge),
908        builders::integer(context, Integer::from(2)),
909    );
910    let normal_form = family.normal_form_wronskian(context, pullback);
911    let product = builders::product(
912        context,
913        vec![
914            gauge_square,
915            ExpressionReference::clone(pullback_derivative),
916            normal_form,
917        ],
918    );
919    crate::simplify::simplify(context, product)
920}

922/// States the chart the substitution stands on.
923///
924/// Four of the obligations are the multipliers the normalization and the transformation divided
925/// by, which must not vanish anywhere the answer is claimed. The fourth is the chart itself: the pullback coordinate
926/// is a real power of `x - center`, and the second solution of either cylinder family — the
927/// function of the second kind — is real only on the positive axis, so the positive-real chart is
928/// where this answer lives. It is also exactly the region the identities above were decided on,
929/// which is what keeps the published claim and its proof the same statement.
930fn chart_obligations(
931    leading: &ExpressionReference,
932    gauge: &ExpressionReference,
933    pullback: &ExpressionReference,
934    pullback_derivative: &ExpressionReference,
935    shifted: &ExpressionReference,
936) -> Vec<OrdinaryDifferentialEquationDomainObligation> {
937    vec![
938        OrdinaryDifferentialEquationDomainObligation::NonzeroExpression(
939            ExpressionReference::clone(leading),
940        ),
941        OrdinaryDifferentialEquationDomainObligation::NonzeroExpression(
942            ExpressionReference::clone(gauge),
943        ),
944        OrdinaryDifferentialEquationDomainObligation::NonzeroExpression(
945            ExpressionReference::clone(pullback),
946        ),
947        OrdinaryDifferentialEquationDomainObligation::NonzeroExpression(
948            ExpressionReference::clone(pullback_derivative),
949        ),
950        OrdinaryDifferentialEquationDomainObligation::PositiveExpression(
951            ExpressionReference::clone(shifted),
952        ),
953    ]
954}

956/// The chart an identity is decided on, realized as a coordinate the algebra can reason about.
957///
958/// A transformed coefficient carries fractional powers of `x - center`, and the automatic
959/// simplifier is right to refuse `w^(-3/2) * w^(1/2) = w^(-1)` for a coordinate that may reach
960/// zero: the rule is false there. Deciding the identity on the chart therefore means deciding it
961/// in a coordinate that is declared to stay on the chart, which is what this surrogate is. The
962/// declaration it carries and the obligation the certificate publishes are the same statement, so
963/// the answer is stated on exactly the region its proof used.
964struct ChartSurrogate {
965    /// Stores the chart coordinate itself, which carries the declaration.
966    coordinate: SymbolIdentifier,
967    /// Stores the replacement of the source coordinate by `center + surrogate`.
968    mapping: SubstitutionMap,
969    /// Stores the replacement of the chart coordinate by `x - center`.
970    inverse: SubstitutionMap,
971}
972
973impl ChartSurrogate {
974    /// Builds the surrogate for a pullback about `center` with the given exponent.
975    fn new(
976        context: &Context,
977        independent_variable: SymbolIdentifier,
978        center: &ExpressionReference,
979    ) -> Self {
980        let surrogate = context.symbol_table.fresh("pullback_chart_coordinate");
981        context.symbol_table.declare_symbol_predicates(
982            surrogate,
983            &[
984                CurrentScalarPredicate::Real,
985                CurrentScalarPredicate::Positive,
986            ],
987        );
988        let coordinate = surrogate;
989        let surrogate = context.interner.intern(ExpressionKind::Symbol(surrogate));
990        let variable = context
991            .interner
992            .intern(ExpressionKind::Symbol(independent_variable));
993        let mut mapping = SubstitutionMap::new();
994        mapping.insert(
995            ExpressionReference::clone(&variable),
996            builders::sum(
997                context,
998                vec![
999                    ExpressionReference::clone(center),
1000                    ExpressionReference::clone(&surrogate),
1001                ],
1002            ),
1003        );
1004        let mut inverse = SubstitutionMap::new();
1005        inverse.insert(
1006            surrogate,
1007            builders::subtract(context, variable, ExpressionReference::clone(center)),
1008        );
1009        Self {
1010            coordinate,
1011            mapping,
1012            inverse,
1013        }
1014    }
1015
1016    /// Moves an expression back off the chart, into the source coordinate.
1017    fn transport_back(
1018        &self,
1019        context: &Context,
1020        expression: &ExpressionReference,
1021    ) -> ExpressionReference {
1022        substitute(context, expression, &self.inverse)
1023    }
1024
1025    /// Moves an expression onto the chart.
1026    fn transport(
1027        &self,
1028        context: &Context,
1029        expression: &ExpressionReference,
1030    ) -> ExpressionReference {
1031        substitute(context, expression, &self.mapping)
1032    }
1033}

1035/// Decides an identity on the chart.
1036///
1037/// The two sides are transported onto the chart coordinate before the difference is taken, so the
1038/// algebra reduces them under the restriction the certificate is stated under and no further.
1039fn proves_zero(
1040    context: &Context,
1041    surrogate: &ChartSurrogate,
1042    left: &ExpressionReference,
1043    right: &ExpressionReference,
1044) -> bool {
1045    let difference = builders::subtract(
1046        context,
1047        surrogate.transport(context, left),
1048        surrogate.transport(context, right),
1049    );
1050    let difference = crate::simplify::simplify(context, difference);
1051    if zero_equivalent(context, &difference, None) == ZeroEquivalenceVerdict::TrueValue {
1052        return true;
1053    }
1054    let expanded = crate::simplify::simplify(context, crate::expand::expand(context, &difference));
1055    zero_equivalent(context, &expanded, None) == ZeroEquivalenceVerdict::TrueValue
1056}
