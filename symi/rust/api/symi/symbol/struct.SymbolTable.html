pub fn name(&self, identifier: SymbolIdentifier) -> Arc<str>

Resolve a symbol identifier to its context-local name.

The name is an owned handle rather than a borrow, so a formatter can resolve an identifier without keeping the registry lock alive for the length of its output.

An identifier this registry never published renders as a visible placeholder rather than aborting. It can only reach here from a value belonging to another generation, and a library panic is not an option: across the WebAssembly boundary it is an opaque RuntimeError that kills the worker, and across the mobile bridge it unwinds into the host application.
