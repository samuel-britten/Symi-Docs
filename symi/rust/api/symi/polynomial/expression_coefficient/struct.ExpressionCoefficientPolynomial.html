Struct ExpressionCoefficientPolynomial 

Source 
pub struct ExpressionCoefficientPolynomial { /* private fields */ }
Expand description

An exact univariate polynomial whose coefficients are arbitrary expressions.

The dense coefficient vector is indexed by degree, so coefficients[k] is the coefficient of variable^k. Every coefficient is independent of variable, which is established structurally when the value is parsed and preserved by every operation on this type. This is an internal working representation: it is not a scalar expression node, and it carries no cache.

Drop the leading coefficients that are exactly zero literals.

Convert to the optimized low-level polynomial when the coefficients permit it.
