pub fn default_context() -> Session

The shared default session that backs every module-level convenience surface.

The session is thread-local because its objects are single-threaded by design: an expression never legally crosses a thread, so one default per thread stays coherent while giving every binding the same default rather than one default per binding. A caller that wants isolation constructs a fresh session instead.

pub fn extend<ReturnType>( &self, computation: impl FnOnce(LentContext<'_>) -> ReturnType, ) -> Result<ReturnType, ApiError>

Runs one embedder-supplied computation against this session’s own context.

A Rust host that builds an application layer on top of this library needs the same context the typed surface computes against: an application whose mathematics is written against the engine’s context must not maintain a second interner, because objects interned in one context are meaningless in another and a reset of one would leave the other stale. This lends the session’s context for the length of one call instead. The computation runs as its own operation, so the work it charges, the records it emits, and the cancellation it observes — including an out-of-band host cancellation request — are the session’s, and a reset that raced the call is reported as a stale object rather than silently accepted.

The context is lent, never given: LentContext cannot outlive the call that received it, so no embedder can hold an independent interner or reset generation.
