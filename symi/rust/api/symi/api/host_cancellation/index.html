The published control record an embedder writes to stop a call it cannot otherwise reach. The control record an embedder writes to stop a call it cannot otherwise reach.

Session::cancel_operation is how a caller inside the process stops one running call. An embedder that entered the library through a synchronous boundary cannot use it, because the thread that would make that call is the one blocked inside the mathematics. What such an embedder does have is the memory the library runs in.

This module publishes a fixed array of words in that memory. A host reserves one word before it starts a unit of work, keeps the index and ticket it is given, and — from wherever it is standing — stores the ticket into the word to ask the work to stop. Every call started on the reserving thread while the reservation is installed observes the word, including the tasks those calls fork onto other threads, so one store stops a whole nest of calls. Releasing the reservation clears the word.

Tickets are what make the array safe to reuse: a store that arrives after the work it named has returned carries a ticket the next reservation of that word does not answer to, so a late request can only fail to stop something. It can never stop a call that started afterwards.
