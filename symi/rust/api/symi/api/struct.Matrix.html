pub fn is_matrix(&self) -> bool

Always true on a matrix, so a mixed result stream can be discriminated.

This predicate and the five below are the matrix side of the shape discriminators an expression also answers. A matrix is never an expression shape, so each of those answers is the constant that says so rather than a computed property.
