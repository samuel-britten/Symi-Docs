Module instrumentation 

Source
Expand description

Advanced native module for instrumentation functionality. Deterministic counters for the cost of a symbolic operation.

The counters answer “how much work did that cost”, in units that do not move between runs, machines or optimisation levels: how many assumption queries were asked, how many model searches ran, how many times the equation dispatcher was entered, how many cylindrical-algebraic lifts happened. Wall time is a signal about a machine; a counter is a property of the algorithm, so a counter is what a cost gate can be written against.

Recording is compiled in only under cfg(test) or the instrumentation feature, so a shipped build carries neither the counters nor the code that increments them.
