Decides the rank of a constants-to-jet Jacobian and turns it into a generality verdict.

The symbolic rank is authoritative: Bareiss reports the generic rank, so a shortfall it can prove really is a deficient family. When pivot selection cannot decide a symbolic entry — exp(c) is nonzero but not provably so without an assumption — the rank is retried at a sample of the constants. Full rank at one parameter point implies full generic rank, which is sound; a shortfall at one point implies nothing, because the point may be non-generic, so it is reported as inconclusive rather than as a deficiency.
