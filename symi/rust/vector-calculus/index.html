                                                                            Vector calculus

                                                                            Coordinates are passed as a list of variable names; vector fields as a list of component expressions in the same order. Empty variable lists and component/variable count mismatches raise.

                                                                            gradient#

                                                                            api::analysis::Session method

                                                                            pub fn gradient<'a, IteratorType, VariableType>(
    &self,
    scalar_field: &Expression,
    variables: IteratorType,
) -> Result<Vec<Expression>, ApiError>
where
    IteratorType: IntoIterator<Item = VariableType>,
    VariableType: Into<VariableLike<'a>>,

                                                                            ∇f\nabla f∇f: the partial derivatives in the order of variables.

                                                                            jacobian#

                                                                            The matrix with entry (i,j)=∂Fi/∂xj(i, j) = \partial F_i/\partial x_j(i,j)=∂Fi​/∂xj​ (rows index components, columns index variables). Returned as a Matrix so the result composes with the matrix methods.

                                                                            hessian#

                                                                            api::analysis::Session method

                                                                            pub fn hessian<'a, IteratorType, VariableType>(

    scalar_field: &Expression,
    variables: IteratorType,

    IteratorType: IntoIterator<Item = VariableType>,
    VariableType: Into<VariableLike<'a>>,

                                                                            The n×nn\times nn×n matrix of second partials, computed as the Jacobian of the gradient; structurally symmetric on smooth input.
